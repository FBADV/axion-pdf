# Axion PDF

**Leia, organize, assine, proteja e converta PDFs. Salve como Word (.docx) ou Markdown (.md).**

Parte da suíte **Axion** da Bernardo Advogados, ao lado do Axion DocX. Funciona no **Windows**, no **Mac** e no **Android**, com o mesmo conjunto de funções, sem conta e sem enviar documentos para a internet: tudo é processado no próprio aparelho.

## Baixar

Abra **[Releases](https://github.com/FBADV/axion-pdf/releases/latest)** e, em **Assets**, baixe o arquivo do seu aparelho:

| Aparelho | Arquivo | Como instalar |
|---|---|---|
| Windows | `Axion PDF ... -Windows-Setup.exe` | Dê dois cliques. Se aparecer o aviso azul do Windows, clique em **Mais informações** e depois em **Executar assim mesmo**. |
| Mac | `... -Mac.dmg` | Abra o arquivo e arraste o Axion PDF para **Aplicativos**. Na primeira vez, clique com o **botão direito** no app e escolha **Abrir**. |
| Android | `... -Android.apk` | Abra o arquivo no celular ou tablet e permita a instalação de fonte desconhecida quando o Android pedir. |

## O que ele faz

Ler, buscar, organizar páginas, juntar e dividir, comentar, preencher e assinar formulários, proteger com senha, redigir (tarjar), OCR, exportar para Word, PowerPoint, HTML, RTF, Markdown, texto e imagens.

## Como as versões são geradas

Cada alteração enviada ao ramo `main` compila automaticamente as três versões pelo GitHub Actions (`.github/workflows/axion-build.yml`) e publica um novo lançamento em Releases.
